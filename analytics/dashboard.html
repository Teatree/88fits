Where the runs come from
  • Played from the editor binary (the Godot editor, or the game started from it): every run lands in analytics/runs/ beside this page, and this page opens the newest one by itself.
  • Tool runs (smoke_run, perf_late, hell_check, captures: anything headless or started with --script): analytics/runs/tools/, shown with the Tool runs switch above.
  • The PC build (88fits.exe): %APPDATA%\Godot\app_userdata\88fits\analytics\runs\ (paste that into Explorer's address bar), then drop a file here. The PC keeps every run file.
  • The phone, and every other player (pass 78): each run's whole record goes to PostHog (run_record, with the player's consent). python tools/posthog_runs.py downloads them into analytics/remote/<player>/ (with your personal key in tools/posthog_personal_key.txt); the Remote runs switch shows them by player: one run with every card, a player's average, several players' average. The how-to: analytics/howto/03_remote_runs.md.
  • Averages: open several run files (or a whole folder) and pick Average: every second of play averaged the way the Level Editor's Sim tab averages its runs, on the Sim's own charts.
  • Every CSV for a whole folder at once: python tools/analytics_csv.py (add --tools for the tool runs, or --runs <folder> for the PC build's folder).
  • Every how-to, by the question it answers (pass 82): analytics/README.md. Players' runs step by step: Remote runs, then How do I get players' runs?, or analytics/howto/03_remote_runs.md.
