1.4 Top five verified blockers to the desired UX

  1. A frame has no identity and no durable home. Every look run rewrites the strip whole (gen_art.process / gen_ctl.main strip.save), recolour rewrites its destination, and clip frames exist only as cache files that re-rolls move aside (_move_clips_aside), that animate.cache_fits/wan_fits invalidate, that free clips re-cut from full_NN (animate.cycle 623-635). Map §4.4 shows layer by layer that no existing layer survives the normal fix paths; the only safe insertion point is a new per-slot store between the clip cache and the pack, read by an Export that packs with a pinned scale. In flight: lane VACE's frames_store.py + frames_export is exactly that layer; what still overwrites it: hand runs and job landings on pinned slots (Q4), and gen_art/gen_ctl not registering their frames (AN-10).
  2. State reaches the browser by pull only, at still/clip granularity. The page polls rev every 2 s and gets the whole 3.3 MB list on any change; progress is stdout regexes and cache-file existence; ComfyUI progress is never bridged (the tool polls /history; the server never talks to ComfyUI during a render).
  3. The Jobs UI rebuilds DOM on change and keeps interaction state on the DOM (sig()'s time term, clear(S.groups), c.__picked, .jreroll, the re-pinned log, assets.js refreshRecord -> redraw rebuilding the whole editor pane). Structural, not a bug.
  4. Generation, installation and import are one motion with no commit boundary. The tool writes the PNG into game/content as it finishes; merge_look sets a page-only fresh flag the game ignores; no previous strip is kept (icons are protected, strips are not); a hand run re-dumps the JSON outside the line-preserving writer.
  5. No evaluator looks at frames, and Claude has no compact result. The only automatic judgments are qa() on stills and a few clip heuristics at generation time; a job returns URLs and a log tail, so a session that wants a verdict opens pictures (the spend of 2026-10-20). Related and verified: the comfy lock has no fairness and a hand run can hold it for a whole pass; _comfy_interrupt clears ComfyUI's whole queue on cancel (an interference bug lane REAL hit the same day).

UI-01 (rejected as proposed). A stream's cadence is bounded by what the server knows: a running record changes when a tool line arrives (_on_line), saved at most every 2.0 s (SAVE_THROTTLE) or on a cache check (5 s); the unit is a still or a clip. SSE on BaseHTTPRequestHandler is feasible (headers without Content-Length, a flush per change, a heartbeat comment every 15 s, one daemon thread per stream, EventSource reconnects with Last-Event-ID = rev), about 150 server lines and 60 client lines, but it adds a thread per tab, a wake-from-sleep failure mode and a file-watch loop for the read-only editor, for ~2 s of latency nobody sees. The dead-simple improvement nobody has made: parse_line already recognises render <key> seed N 12.3s ok; harvesting outputs on that line instead of on the 5 s workflows-folder check shows a landed still within one poll. The bus is designed so the transport can change underneath it: the page consumes {rev, changed, removed} whether it polled or was pushed. Done when a changed poll while one job runs transfers kilobytes, not megabytes.

UI-02 (accepted). F6. Critical recommendations

Top five highest-ROI improvements, ranked

  1. Finish and harden the frame layer lane VACE built (AN-06/08/09/10/14 + WF-04's strip backup). It is the only insertion point that survives the normal fix paths (blocker 1), it already runs end to end on SP-B, and the hardening is small: one writer of staged.json, the shrink guard, the hook after strip.save, rollback, retention, a backup on every landing. Without it, every other repair idea is undone by the next re-roll. Journeys 2-5 ride on it.
  2. UI-04, stable cards. The verified daily annoyance (a running card rebuilt every 2 s, picks and panels lost), fixable in one module with the pattern looks.js already follows; it de-risks every later live surface and the Frames view.
  3. AI-05's compact handoff (then WF-01's request fold). The principal token saver: Claude queues with one command and reads one paragraph plus, at most, one downscaled sheet path; the cost laws measured in part_AI show that the number of pictures in the top model's context, not the model's price, is the lever.
  4. AI-07's tiers with AI-01's ledger, gated by AI-08's blind bench. Deterministic checks on everything, the free local eye on flagged frames, a pinned cheap Claude model only on contact sheets at decision points under a daily ceiling; the bench stops money being spent on an eye that cannot count (measured: none of the four could).
  5. UI-02's delta protocol and connection line (with WF-06(c)'s cancel fix as its small sibling). A changed poll goes from 3.3 MB to kilobytes, "offline" becomes a true sentence with a time, a reload returns to the same frame; and a cancel stops clearing a hand run's ComfyUI prompt (a verified interference bug).

Top five to reject, simplify or defer (defer = sequence, not a fourth status)

  1. UI-03 React/TypeScript/Vite: reject. A toolchain, a test runner and interop with every imperative component for a rendering-discipline problem a 40-line helper fixes.
  2. UI-01 an event stream now: reject (revisit after WF-07). The server has nothing sub-second to push; the payload, not the pull, is the cost.
  3. AI-06 agy/Antigravity/consumer-OAuth Gemini: reject. No supported scriptable image route exists; the only honest Gemini route is a paid API key, proven blind first.
  4. WF-02's SQLite and UI-05's separate Art Studio tab: simplify. An append-only JSONL with a seq and an integrated expansion of the look card give the same outcomes without a second truth or a fourth live surface.
  5. Defer: UI-08's drawn regions until G1 shows a partial mask works; UI-06's substage until WF-07 lands; AI-04's Auto-iterate until G2 shows an eye worth trusting (Auto-select rejected outright); OPS-01's fixtures for streaming/quota/bad-AI-JSON until their features exist; the comfy-lock FIFO ticket unless hand-run contention persists after pass 95.
