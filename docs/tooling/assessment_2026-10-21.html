1.4 Top five verified blockers to the desired UX

  1. A frame has no identity and no durable home. Every look run rewrites the strip whole (gen_art.process / gen_ctl.main strip.save), recolour rewrites its destination, and clip frames exist only as cache files that re-rolls move aside (_move_clips_aside), that animate.cache_fits/wan_fits invalidate, that free clips re-cut from full_NN (animate.cycle 623-635). Map §4.4 shows layer by layer that no existing layer survives the normal fix paths; the only safe insertion point is a new per-slot store between the clip cache and the pack, read by an Export that packs with a pinned scale. Built (lane VACE): frames_store.py + frames_export is exactly that layer, and gen_art/gen_ctl now register their frames through hook_after_save (AN-10); what still overwrites the game's strip on pinned slots is a landing or a hand run, which revision 2 closes with Garry's point 4 (the pins re-applied at every landing, AN-09).
  2. State reaches the browser by pull only, at still/clip granularity. The page polls rev every 2 s and gets the whole 3.3 MB list on any change; progress is stdout regexes and cache-file existence; ComfyUI progress is never bridged (the tool polls /history; the server never talks to ComfyUI during a render).
  3. The Jobs UI rebuilds DOM on change and keeps interaction state on the DOM (sig()'s time term, clear(S.groups), c.__picked, .jreroll, the re-pinned log, assets.js refreshRecord -> redraw rebuilding the whole editor pane). Structural, not a bug.
  4. Generation, installation and import are one motion with no commit boundary. The tool writes the PNG into game/content as it finishes; merge_look sets a page-only fresh flag the game ignores; no previous strip is kept (icons are protected, strips are not); a hand run re-dumps the JSON outside the line-preserving writer.
  5. No evaluator looks at frames, and Claude has no compact result. The only automatic judgments are qa() on stills and a few clip heuristics at generation time; a job returns URLs and a log tail, so a session that wants a verdict opens pictures (the spend of 2026-10-20). Related and verified: the comfy lock has no fairness and a hand run can hold it for a whole pass; _comfy_interrupt clears ComfyUI's whole queue on cancel (an interference bug lane REAL hit the same day).
