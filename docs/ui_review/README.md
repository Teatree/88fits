# How to use this pack

For Claude Design: attach `88fits_ui_review.pdf` (the brief, the game's painted art and every screen with its screenshots beside its notes, in one file) and ask for the critique and the directions it describes. Attach no design system: the look is open. `art/` holds the icons one by one, to attach any the mocks should use. The Markdown files, `screens/` and the two art sheets hold the same content for tools that want them apart.

Made by tools/make_ui_review.py from the game's own screenshots and the content folders' icons. Captures (1080x1920, windowed, bounded): `bash tools/ui_review_capture.sh` runs game/tools/wanted_shots.gd, uidoc_shots.gd, screenshot_run.gd, _p112_wanted_shots.gd, _p111_skins_shot.gd, _p116_RESULTS_shots.gd and _p115_META_shots.gd into tools/dl/p116/UIREVIEW/<set>/; then `python tools/make_ui_review.py [--caps=<dir>]`. The totem/ folder is a separate, older brief for the Totem screen alone. docs/ui_screens/ is the plain reference of every screen (not a review).
