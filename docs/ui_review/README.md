# How to use this pack

For Claude Design: attach `88fits_ui_review.pdf` (the brief, the game's painted art and every screen with its screenshots beside its notes, in one file) and ask for the critique and the three visual directions it describes. Attach no design system: the look is open. `art/` holds the icons one by one, to attach any the mocks should use. The Markdown files, `screens/` and the two art sheets hold the same content for tools that want them apart.

Made by tools/make_ui_review.py from the game's own screenshots (tools/screenshot_run.gd and tools/ui_shots.gd) and the content folders' icons.
